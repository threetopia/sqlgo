## 1. Scope and Data Ownership

`sqlgo` owns no database schema. It does not create, read, update, or delete persisted data. It receives Go values from the caller, formats SQL text, and keeps the values in an in-memory parameter registry for the duration of a build.

This document describes three things:

- The in-memory data model used to generate placeholders and argument slices.
- The Go value types the library accepts and how it forwards them to `database/sql`.
- The PostgreSQL data features the generated SQL depends on.

There are no migrations, backfills, retention rules, or schema changes.

## 2. Data Model

| Entity | Description | Lifetime |
|---|---|---|
| Parameter registry | Ordered value list plus a hash-to-ordinal map. | One builder |
| Parameter entry | A Go value, its Go type name, a SHA-1 hash, and a 1-based ordinal. | One builder |
| Clause item | A typed wrapper that describes one projection, condition, assignment, or join. | One builder |
| Generated statement | SQL text plus the ordered argument slice returned to the caller. | One call to `BuildSQL()` |

The registry is the only place that assigns ordinals. Clause modules never create placeholder numbers directly. They call `SetSQLParameter`, then read the sign with `GetSQLParameterSign`.

## 3. Data Dictionary

### 3.1 Scalar values

Scalar values are accepted wherever a `sqlGoValue` is expected, because the type is `interface{}`. The library forwards them to `lib/pq` unchanged.

| Go type | Accepted | SQL usage | Notes |
|---|---|---|---|
| `string` | Yes | Comparison values, insert values, update values, full-text values, similarity values, vector literals | The most common value type. |
| Signed and unsigned integers | Yes | Numeric comparisons and assignments | `lib/pq` handles the encoding. |
| `float32`, `float64` | Yes | Numeric comparisons, thresholds, vector values | The where-similarity threshold is always `float64`. |
| `bool` | Yes | Boolean comparisons and assignments | |
| `time.Time` | Yes | Timestamp comparisons and assignments | Also supported inside slices. |
| `nil` | No | Not registered | `SetSQLParameter` returns early, so a clause that uses it renders `$-1`. |

### 3.2 Slice values

Slices are accepted in WHERE and join conditions. Behavior depends on the operator.

| Go type | `IN` / `NOT IN` | Other operators |
|---|---|---|
| `[]string` | One placeholder per element | `pq.Array`, one placeholder |
| `[]int` | One placeholder per element | `pq.Array`, one placeholder |
| `[]int32` | One placeholder per element | `pq.Array`, one placeholder |
| `[]int64` | One placeholder per element | `pq.Array`, one placeholder |
| `[]float32` | One placeholder per element | `pq.Array`, one placeholder |
| `[]float64` | One placeholder per element | `pq.Array`, one placeholder |
| `[]bool` | One placeholder per element | `pq.Array`, one placeholder |
| `[]time.Time` | One placeholder per element | `pq.Array`, one placeholder |

Duplicate elements are removed before registration. The remaining elements keep their first-appearance order.

### 3.3 Clause value wrappers

| Wrapper | Created by | Parameters registered | SQL shape |
|---|---|---|---|
| `sqlGoWhereBetween` | `SetSQLWhereBetween` | First bound, second bound | `(column BETWEEN $a AND $b)` |
| `sqlGoWhereToTsQuery` | `SetSQLWhereToTsQuery` | Query value | `column @@ to_tsquery('lang', $N)` |
| `sqlGoSimilarity` | `SetSQLWhereSimilarity` | Value, threshold | `similarity(column, $N) operator $M` |
| `sqlGoSelectTsRank` | `SetSQLSelectTsRank` | Query value | `ts_rank(column, to_tsquery('lang', $N))` |
| `sqlGoSelectDistinct` | `SetSQLSelectDistinct` | None | `DISTINCT ON (column) column` |
| `sqlGoSelectEmbedding` | `SetSQLSelectEmbedding` | Vector value | `(column operator $N)` or `prefix(column operator $N)` |
| `sqlGoSelectEmbeddingArray` | `SetSQLSelectEmbeddingArray` | One per vector element | `prefix(column operator ARRAY[$N,$M,...])` |
| `sqlGoSelectSimilarity` | `SetSQLSelectSimilarity` | Value | `similarity(column, $N)` |
| `sqlGoInsertToTsVector` | `SetSQLInsertToTsVector` | Text value | `to_tsvector('lang', $N)` |
| `sqlGoUpdateToTsVector` | `SetSQLUpdateToTsVector` | Text value | `column=to_tsvector('lang', $N)` |

### 3.4 Identifiers and literals

| Data | Parameterized | Notes |
|---|---|---|
| Schema name | No | Rendered as `schema.`; first value wins. |
| Table name | No | Written as provided. |
| Column name | No | Written as provided. |
| Alias | No | Written as provided. |
| Operator | No | Written as provided. |
| Join type | No | Uppercased before rendering. |
| Text search language | No | Interpolated inside single quotes. |
| Vector operator | No | Written as provided. |
| Comparison values | Yes | Registered through the parameter registry. |

Callers are responsible for trusted identifiers and language names. The library does not quote or escape them.

## 4. Integrity Rules

- Placeholder ordinals start at `1` and are contiguous in first-appearance order.
- A value is identified by the SHA-1 hash of its JSON encoding plus its Go type name.
- Identical value and type pairs share one ordinal. Different types do not share an ordinal.
- The ordered argument slice matches the ordinal order: element at index `0` is `$1`, index `1` is `$2`, and so on.
- Array elements are deduplicated before registration, and the first occurrence wins.
- The registry does not compare original values after a hash match. A hash collision would merge two different values.
- `SetSQLParameter(nil)` does not register the value.
- `GetSQLParameterSign` for an unregistered value returns `$-1`.
- A builder owns one registry. Sharing a builder across goroutines can corrupt the list and map.

## 5. Access Patterns

### 5.1 Write path

1. A clause module receives a value.
2. It calls `SetSQLParameter(value)`.
3. The registry computes the hash, checks the map, appends the value when new, and records the ordinal.
4. The clause module calls `GetSQLParameterSign(value)` and writes the sign into its SQL fragment.

### 5.2 Read path

1. The caller calls `GetSQLParameter()`.
2. The registry returns the ordered `[]interface{}`.
3. The caller passes the slice to `db.Query`, `db.Exec`, or `db.QueryRow` with the matching SQL string.

### 5.3 Lookup path

`GetSQLParameterCount(value)` returns the ordinal for a registered value or `-1`. `GetSQLParameterSign(value)` uses that ordinal to build `$N`.

## 6. PostgreSQL Data Requirements

| Feature | Requirement | Used by |
|---|---|---|
| Full-text search | Built-in `tsvector` and `tsquery` types and functions. | `FR-016` |
| Trigram similarity | `pg_trgm` extension for `similarity()`. | `FR-017` |
| Vector distance | `pgvector` extension for vector columns and distance operators. | `FR-018` |
| Array encoding | `lib/pq` array support for slice values outside `IN` and `NOT IN`. | `FR-004` |
| Placeholder syntax | PostgreSQL `$N` placeholders. | All requirements |

The library does not create extensions, tables, columns, indexes, or types. The target database and the caller own those objects.

## 7. Impact on Existing Data

None. The library only produces SQL text and Go argument slices. It does not read or write persisted data, and the specification work introduces no schema change.

## 8. Open Questions

| Topic | Question | Impact |
|---|---|---|
| Deduplication | Is identical-value deduplication intentional? `TestToTsQuery` and `TestToTsQueryPrepend` expect separate placeholders for the same value. | Decide whether to fix the tests or change the registry. |
| `nil` values | Should `nil` be rejected earlier, rendered as `NULL`, or documented as unsupported? | Current behavior renders `$-1`. |
| Special operator map | Should the `TO TSQUERY` mapping remain when `SetSQLWhereToTsQuery` uses a dedicated type? | Dead mapping. |
| Subquery join | Should a subquery join use `ON` instead of `WHERE`? | Current output can be invalid SQL for that case. |
| Identifier safety | Should the library quote or validate identifiers? | Callers currently carry this responsibility. |
| Hash collisions | Is a secondary value comparison needed after a hash match? | Low risk, but the registry does not verify collisions. |
