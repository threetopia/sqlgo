## 2. Test Objectives and Scope

### 2.1 Behavior Verified

- The SQL string produced by every clause matches the documented shape exactly, including spaces.
- Dynamic values are registered as bound parameters and never interpolated into the SQL text.
- The ordered argument slice matches the placeholder ordinals.
- The prepend/chain style, the `Set*` style, and direct module wiring produce identical SQL.
- The facade composes clauses in a fixed order regardless of the order the caller uses.
- PostgreSQL full-text, trigram similarity, and vector constructors emit the documented SQL.
- Documented edge, error, and unsupported states are observable.

### 2.2 Requirements Covered

- `FR-001` to `FR-019` from the FSD.
- Data integrity rules from DRD section 4.
- Technical contracts from TSD sections 3, 5, 6, 7, 9, and 10.

### 2.3 Exclusions

- Live database execution, driver encoding, and PostgreSQL extension behavior. The library only produces SQL text and Go values.
- Connection pooling, transactions, migrations, and ORM behavior.
- MySQL-specific SQL. `MySQLDialect` exists as a constant, but no builder branch uses it.
- Performance targets and concurrency safety. The builder is documented as not safe for concurrent use.
- AI agent, LLM, tool calling, and retrieval behavior. The library has none.

### 2.4 Dependencies, Preconditions, and Environment Assumptions

Shared preconditions referenced by the test cases:

- **P1:** Go 1.18 toolchain, package `sqlgo`, and `github.com/lib/pq` available. No database connection is opened.
- **P2:** A fresh `NewSQLGo()` builder with no clauses. `BuildSQL()` is called exactly once at the end of the case, then `GetSQLGoParameter().GetSQLParameter()` is read.
- **P3:** SQL is compared as an exact string, including spaces. Parameter slices are compared by value and order.

Environment assumptions:

- PostgreSQL `$N` placeholder syntax is the target.
- `pg_trgm` and `pgvector` are only relevant to the generated SQL text in this TCD. No extension is installed or exercised.
- No environment variable, model version, prompt version, or service version affects the result.

    And GetSQLParameter returns an empty slice

## 9. Assumptions, Open Questions, and Coverage Gaps

| Type | Item | Impact |
|---|---|---|
| Assumption | PostgreSQL `$N` placeholders are the target syntax. | MySQL placeholder behavior is not tested. |
| Assumption | Exact SQL spacing follows `fmt.Sprintf` output and the constants in `sqlgo_test.go`. | Cases with spacing defects are recorded as open questions rather than silently normalized. |
| Assumption | The library never executes SQL and is tested without a live database. | Driver encoding and extension behavior are out of scope. |
| Open question | **OQ-001:** Identical value deduplication conflicts with `TestToTsQuery` and `TestToTsQueryPrepend`, which expect `$2` while the registry returns `$1`. | `TC-REG-001` follows `FR-006`. Decide whether to fix the tests or the registry. |
| Open question | **OQ-002:** A subquery JOIN appends its condition with `WHERE` instead of `ON`. | `TC-JOIN-005` expects `ON`. The current output can be invalid SQL. |
| Open question | **OQ-003:** The `TO TSQUERY` entry in `specialOperator` is unreachable because `SetSQLWhereToTsQuery` uses a dedicated type. `buildWhereSlice` also contains an empty `TS VECTOR` branch. | Dead code. No behavior test is defined. |
| Open question | **OQ-004:** A subquery in ORDER BY loses the `ORDER BY` prefix and any previous order items. Observed output: `SELECT x FROM table AS t (SELECT id FROM other AS o) ASC`. | No test case covers this. The output is invalid SQL. Decide whether to fix the order builder or document the limitation. |
| Open question | **OQ-005:** `SetSQLSelectEmbedding` with a non-empty prefix inserts an extra space before the prefix. Observed output: `SELECT ts_rank(...) AS rank,  1-(embedding <=> $2) AS similarity`. | `TC-VECTOR-002` expects the documented single-space shape. Decide whether to normalize the format string. |
| Open question | **OQ-006:** `nil` values are skipped by the registry and render `$-1`. | `TC-PARAM-005` records `$-1`. Decide whether to reject, render `NULL`, or document `nil` as unsupported. |
| Open question | **OQ-007:** `SetSQLPage` reads the current limit, so the limit must be set before the page. | `TC-LIMIT-005` and `TC-REG-002` record both orders. Decide whether to make the helper order-independent. |
| Open question | **OQ-008:** Identifiers, aliases, operators, and language names are interpolated without quoting or validation. | `TC-SEC-002` and `TC-REG-004` record the risk. Callers must validate trusted input. |
| Open question | **OQ-009:** The parameter registry does not compare original values after a hash match. | A hash collision would merge two different values. Low risk, not practically testable. |
| Open question | **OQ-010:** A builder holds mutable state and is not safe for concurrent use. Reuse after `BuildSQL()` is not part of the contract. | `TC-REG-003` records idempotent reuse for the same builder. Concurrency is not tested. |
